# Minigame 1
## Devlog

I think of a Scene as a mountain park, GameObjects as the trails, rocks, and hikers in it, and Components as the properties and abilities that determine how each one works. For example, a Collider makes a rock solid, while a movement script lets a hiker move and jump. In my level, I rearranged the platforms into three climbable mountains, placed coins and hazards along the routes, and adjusted the player’s speed. Together, these GameObjects and their Components create the climbing experience within the Scene.
